# Cools 垂直电·光·热互连平台

[English](README.md) | [한국어](README_KR.md) | [专利组合](PATENT_PORTFOLIO.md) | [公开声明](PUBLIC_NOTICE.md)

## 数据、电力和热不再争夺封装平面面积。

Cools 在上部与下部半导体器件之间配置透明单晶处理层，并通过同一处理层同时实现：

1. **光数据的垂直传输**
2. **电力的垂直供应**
3. **热量的垂直导出**

同一单晶本体兼作光学介质、电源通孔的绝缘主体、导热体，并在适当情况下作为单片集成 III-V 光源的外延母衬底。

---

## 1. 平面资源瓶颈

传统封装主要通过封装平面或单一背面方向处理数据、电力和热。

```text
数据 → Cu/RDL/中介层平面布线
电力 → TSV + 平面电源分配
热量 → 背面 TIM + 外部散热器
```

随着带宽和功率密度提高，三种功能争夺同一封装面积。

Cools 架构把三者转向厚度方向。

```text
上部器件
    │ 光通道
    │ 电源通孔
    │ 导热/冷却通道
    ▼
透明单晶处理层
    ▼
下部器件
```

---

## 2. 一个单晶本体承担四种材料功能

处理层在单一材料中结合：

- 工作波长下的光学透明性
- 高电阻率
- 高于常规封装绝缘材料的热导率
- 与 III-V 发光结构外延生长的兼容性

单晶蓝宝石是主要实施例，因为它同时具备宽波段透明性、电绝缘性、有效热传导、机械强度以及成熟的 GaN 外延基础。

根据应用，也可考虑单晶 AlN、SiC 或 Ga₂O₃。

---

## 3. 垂直光通道

光发射器与光探测器位于处理层两侧并相互对准。光信号可通过以下路径传播：

- 透明晶体内部的自由空间传播
- 离子注入折射率调制芯
- 异质薄膜波导
- 微透镜辅助路径
- 上述结构的组合

该架构支持空间并行和波分复用。

### 光源分支

1. 直接生长于蓝宝石处理层上的 GaN/InGaN 微型 LED 阵列
2. 与外部连续波光源组合的光调制器
3. 用于高速或特定波长工作的键合激光二极管

---

## 4. 垂直供电

由于处理层本体为绝缘体，可在晶体中形成导电通孔，同时降低对半导体中介层式通孔绝缘衬里的依赖。

电源通孔区域与光输入输出区域在平面上分离，因此可以在不遮挡光路的情况下实现较高垂直电流密度。

---

## 5. 垂直热通道

单晶处理层本体在堆叠器件与外部冷却边界之间形成导热路径。

可通过以下方式强化散热：

- 晶体本体固体传导
- 局部热扩散区
- 处理层内部微通道
- 冷却液主动流动
- 光学区之外的热通孔或导热插入物
- 双面冷却

---

## 6. 区域分离式三合一架构

```text
处理层平面
┌──────────────────────────────────────────┐
│ 光 I/O 区 │ 电源通孔区 │ 冷却区          │
└──────────────────────────────────────────┘
      │             │             │
      ▼             ▼             ▼
   垂直光传输    垂直电流      垂直散热
```

平面区域分离可防止导电通孔遮挡光路、冷却液和气泡引起光散射、电流路径与光路径相互干扰，以及冷却通道占用光通道面积。

---

## 7. 代表应用

- GPU 与 HBM 之间的大规模并行垂直光互连
- 逻辑芯片、NPU、Chiplet、传感器与光引擎堆叠
- 高面密度光存储与加速器互连
- 可见光、近红外以及适当设计下的中红外多波长链路

---

## 8. 与普通中介层的区别

| 功能 | 传统中介层 | Cools 透明单晶处理层 |
|---|---|---|
| 数据 | 主要为平面电布线 | 垂直光传输 |
| 电力 | TSV 与平面再分配 | 绝缘本体中的垂直导电通孔 |
| 热量 | 独立背面热堆叠 | 处理层本体及内置冷却路径 |
| 光源 | 通常单独键合 | 可单片外延集成 |
| 平面面积竞争 | 高 | 通过厚度方向分离降低 |

## 9. 专利结构

平台覆盖：

- 器件之间的透明单晶处理层
- 穿过处理层的垂直光信号
- 穿过绝缘本体的电源通孔
- 固体或流体垂直散热路径
- 光、电、热区域的平面分区
- 单片、调制器和键合光源分支
- 自由空间、离子注入芯和薄膜波导分支
- 空间与波长复用
- 集成封装制造流程
